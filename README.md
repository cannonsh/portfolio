# portfolio

Personal portfolio site for [Lovro Papež](https://github.com/sloveniangooner).

## Tech

- **HTML** — static single-page layout
- **Tailwind CSS v4** — utility-first styling
- **@tailwindcss/cli** — builds `src/style.css` → `dist/style.css`
- **Yarn** — package manager

## Usage

```bash
yarn install

# Development (watch mode)
yarn dev

# Production build
yarn build
```

Open `index.html` in a browser while `yarn dev` is running.
